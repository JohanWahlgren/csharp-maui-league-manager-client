# League manager client (.NET MAUI)

A cross-platform desktop client application built with .NET MAUI. The application provides a graphical user interface for users to interact with the league manager system, consuming data dynamically from the backend REST API.

## Backend API
This client consumes data from the [League Manager WebAPI](https://github.com/JohanWahlgren/csharp-webapi-league-manager.git)

## Tech stack:
- C#
- .NET MAUI
- HTTP Client (REST communication)
